# 可复用方法模式

以下名称是本技能为了调用方便的原创命名，不冒称作者提出同名框架。

## P1：任务—信息—测量链
**何时用**：新测试任务或方案不完整。
**步骤**：定义目标量和结论 → 确定频带、幅值、环境及误差 → 选转换原理 → 激励/调理 → 同步采集 → 记录 → 特征分析 → 用已知输入验证。
**取舍**：按需要保留信息；更多通道和更高fs增加成本，不自动提高可信度。依据：绪论p.1–5及第7、9章。

## P2：静态合格，动态再验
**何时用**：静态标定准确，但实际波形偏小、迟滞或变形。
**步骤**：查零点与量程 → 识别一/二阶或更完整模型 → 把安装和各级串联 → 对实际频带检查幅相 → 设计已知频率验证。
**取舍**：带宽、灵敏度、噪声与安装刚度不总同向。依据：第2章p.44–57。

## P3：桥路从分压开始
**何时用**：应变、电容、电感转换或灵敏度算错符号。
**步骤**：标电源/输出端 → 列各桥臂与变化方向 → 求精确复阻抗/电阻分压 → 检查零点 → 作小变化线性化 → 验温度和寄生量。
**取舍**：差动有赖匹配，交流平衡还需相位条件。依据：第3、5章。

## P4：采样前防不可逆损失
**何时用**：谱中出现可疑低频，或计划数字化。
**步骤**：看模拟带外成分 → 给模拟滤波器留过渡带 → 定fs与每通道时序 → 设增益及过载余量 → 检查量化和噪声 → 采后看波形再FFT。
**取舍**：模拟带宽不足、混叠、饱和均不能靠后处理完全恢复。依据：第5章p.170–175、第7章p.201。

## P5：频谱问题三分法
**何时用**：峰变宽、峰位变化、加窗后幅值不一致。
**步骤**：先排混叠 → 检查截断与窗 → 检查DFT栅格 → 检查归一化/单边谱 → 延长真实观察时长做对照。
**取舍**：窗抑制旁瓣但加宽主瓣；补零不是延长记录。依据：第7章p.201–203。

## P6：同步误差转相位预算
**何时用**：互谱、模态、轴轨迹或延时比较。
**步骤**：列采样结构和时间差 → 算360fΔt → 与允许相位误差比 → 决定分时/同时保持/独立ADC → 用同源信号验证。
**取舍**：硬件成本与保持误差、通道延迟同时评估。依据：第7章p.207–208；相位预算是推导扩展。

## P7：安装属于模型
**何时用**：换探头或安装后结果改变。
**步骤**：列质量/刚度/热阻/管容/声场等耦合 → 判断对静态及动态的作用 → 必要时建等效环节 → 全链复标。
**取舍**：非接触可能减少加载，但仍受材料、光路和几何影响。依据：第3章及第9章p.235–290。

## P8：数值、语义和有效性分开
**何时用**：智能/模糊传感器或虚拟仪器显示结果。
**步骤**：保留原始数值 → 保存补偿模型及适用域 → 生成语义/状态 → 记录参数版本 → 用独立输入验证。
**取舍**：自检不等于准确，隶属度不等于概率。依据：第4、8章；记录契约是工程化扩展。
