# 提取、整理与质量范围

整理日期：2026-10-20。书名、主编/主审、出版社、2002年3月第1版及ISBN由PDF封面、题名页与版权页定位核对。源文件指纹在[source-index.json](source-index.json)。

## 实际完成的工作
1. 调用本机book-to-skill提取入口，发现扫描PDF无有效正文文本层，初始pypdf回退提取不能用于学习。
2. 在本地隔离Python环境使用PyMuPDF渲染、RapidOCR进行308/308页逐页OCR。OCR识别出11779条文本行，共212442个字符；这些是识别结果计数，不是原书字数、阅读token计费或OCR准确率。
3. 按9章、46小节建立导航；按目录和正文分段阅读/抽查，提炼决策规则、步骤、取舍和反例；并非对全书逐字人工校对或全部习题求解。
4. 直接查看选定原页，核验核心统计、频响、阶跃、桥路、采样、声压级等公式；具体范围在[核验表](formula-audit.md)。不将未查看的公式声称已核验。
5. 生成9个章节技能文件、主入口、术语、方法、速查、学习路径，以及自编教学计算程序与测试。

## OCR质量指标如何解释
- 行识别模型平均分约0.958680，低于0.8的行有774条；**模型分数不是经人工标注测得的准确率**，更不能证明公式正确。
- 全文平均分会被大量普通文字主导；上下标、希腊字母、正负号、表格列对应和电路连接仍可能丢失。
- 只有明确标为V的条目经过列明范围的视觉核验；D是教学定义/推导；U仍需查原书。
- 逐页统计公开在[ocr-metrics.json](ocr-metrics.json)，不含任何正文、扫描图片、全文OCR或用户本地路径。

## 页码与差异
- 正文/参考文献印刷p.1–294对应PDF10–303，区间内PDF页=印刷页+9。
- 第4章目录写123，实际章首页PDF131，应定位为逻辑印刷p.122；章首页未显示页码，由前一页p.121与后一页p.123及连续顺序定位。
- 第9章p.240 / PDF249的阻抗概述与列式分子分母方向不一致；技能明确采用F/X、F/V、F/A并区分倒数导纳。
- 第9章章首页及正文使用“典型非电量参量的测量方法”，章节文件沿用该写法；不凭OCR自动纠正原书用语。

## 内容性质与时代边界
- 章节文件是AI辅助的原创结构化提炼，不是原书逐段替代品。
- 全部数值教学例均标记自编，代码为原创实现；未复制教材完整例题、长代码或表格。
- 智能传感器、模糊映射、虚拟仪器的架构思想与工程化验证规则分开说明，未将新命名的方法冒称作者原有框架。
- 当前标准、噪声合格限值、软件菜单/API、采购与器件性能未作现行性研究；本项目不提供合规或安全认证结论。
