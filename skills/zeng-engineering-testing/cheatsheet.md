# 决策速查：先做什么，何时换方案

| 如果看到/需要 | 先做 | 因为/不要做 |
|---|---|---|
| 读数准但动态峰值偏小 | 合成全链频响，查频带 | 静态标定不能排除动态衰减 |
| 慢变小信号漂移 | 查零点、热漂、调制/相敏链 | 不只是增加增益 |
| 桥路信号变成反号或消失 | 画分压、标桥臂变化方向 | “半桥/全桥”不决定全部符号 |
| 微弱信号要数字化 | 预算桥输出、增益、噪声、ADC跨度 | 位数不等于准确度 |
| 高频折出奇怪低频 | 采样前限制带宽，核每通道fs | 采后低通不撤销混叠 |
| 相近谱线难分 | 延长真实记录，评估窗主瓣 | 补零只加密频点显示 |
| 加窗后幅值不同 | 查窗增益和谱归一化 | 不把不同算法曲线直接叠加判异常 |
| 传递函数需相位 | 用互谱并查共轭约定 | 两个自谱比不能给完整相位 |
| 多通道要比相位 | 查采样时差，算360fΔt | 主机同时显示≠同时采样 |
| 长期静态力/压力 | 优先考虑可测静态的原理并标定 | 不盲用会泄漏的压电链 |
| 涡流位移换靶材料 | 重新检验标定 | 导电性/表面会改变输出 |
| 温度变化快 | 查热惯性与接触条件 | 静态精度高不保证跟得上 |
| 热电偶参考端变化 | 测参考端并正确补偿 | 补偿导线不是无限适用的消误器 |
| 动态压力用长引压管 | 把管道—容腔纳入动态模型 | 本体带宽不等于系统带宽 |
| 转速显示疑似倍频 | 查每转计数与频闪倍/分频 | 视觉静止不代表真实停机 |
| 两个声级要叠加 | 确认不相干，再按能量相加 | dB不能线性相加 |
| 模糊结果0.7 | 说明概念与隶属度定义 | 不解释为概率70% |
| 记录文件很大仍丢样 | 查持续速率、缓冲、显示阻塞 | 容量足够不保证不中断 |
| 用旧书做合格判定 | 查当前适用标准和量值定义 | 2002年的限值不作当前依据 |

## 按问题选章
- 信号是什么、怎么算强度 → 第1章；装置跟不跟得上 → 第2章。
- 用什么敏感机理 → 第3章；是否需要补偿与语义输出 → 第4章。
- 怎么送入采集卡 → 第5章；怎么保存与重放 → 第6章。
- 怎么分析、同步采集 → 第7章；怎么组织成仪器 → 第8章。
- 现场振动/位移/转速/噪声/温压 → 第9章，联合相关基础章。

## 提交结论前的最短检查
物理量与单位 → 量程/过载 → 频带/安装 → 校准 → 同步/采样 → 数据有效性 → 处理参数 → 条件与局限。
