# 第5章：信号调理方法

**定位**：印刷p.143–176 / PDF第152–185页。电桥p.143；调制解调p.149；滤波p.159；A/D p.170。

## 核心问题
调理的目的不是一味放大，而是让传感器的输出满足保真、抗干扰、量程与数字化要求。每一环节都可能增加误差、相位变化或信息损失。

## 方法一：先画桥路再决定灵敏度与符号
1. 标出供电两端、输出两端和四个桥臂，明确测量极性。
2. 写两支路分压的差值，先检查零输入时是否平衡。
3. 指定哪些桥臂变化、变化方向是否同号、温度影响作用于哪些桥臂。
4. 从精确式作小量近似，验证ΔR/R足够小，再判断单臂、半桥或全桥的灵敏度。
5. 交流桥还需同时满足阻抗幅值与相位平衡；只调电阻不一定能平衡寄生电容。

本仓库定义供电为上下端、电压为左中点减右中点：
`V_out=V_ex[R_2/(R_1+R_2)-R_4/(R_3+R_4)]`。
此标号为自定义，不直接套原书图号。等阻桥仅R1增加ΔR时：
`V_out=-V_ex ΔR/[2(2R+ΔR)]≈-V_ex(ΔR/R)/4`。

## 方法二：用调制搬移信号，再用匹配的解调恢复
缓变微弱信号容易受零漂等影响，可用载波调制，把被测信号的信息搬到另一频带后放大。调幅把幅值信息移到载波两侧；解调后还要低通。

- 单纯整流/包络检波可能丢失原低频信号的正负号；有方向要求时考虑相敏检波。
- 相敏检波需要相位参考与同步关系，参考相位误差会改变结果。
- 调频与鉴频关注频率变化；不能把调幅的增益公式直接用于调频链。
- 滤除载波和保证调制信号带宽是同时需要满足的约束。

## 方法三：把滤波器规格写成完整约束
| 需求 | 应写出的条件 | 代价 |
|---|---|---|
| 去除漂移 | 高通下限及低频信号允许损失 | 直流与缓变成分被改变 |
| 保留有限频带 | 通带、允许波纹、相位/延迟 | 过渡带不能为零 |
| 抗混叠 | 采样前模拟滤波、阻带衰减与fs | 仅靠采样后处理无效 |
| 分离相近频率 | 带宽与选择性 | 稳态建立/分析时间增加 |
| 多级滤波 | 合成传递函数、负载匹配 | 级联可能互相加载 |

理想砖墙滤波器是分析模型，不是可零延迟实现的实物。截止点常用约−3 dB定义，这意味着幅值约0.707倍，不是测量误差为零。无源网络直接级联时不能忽略后级负载。

## 方法四：分开采样、量化与编码
- **采样**决定时间离散；**量化**决定幅值离散；**编码**决定数字表示。
- 采样/保持期间需给转换器稳定输入；多通道还要检查切换建立与每通道实际采样率。
- 计数式、逐次逼近式与双积分式的速度、抗干扰与结构取舍不同，不用旧书器件速度当当前上限。
- n位只表示码数，不等于系统准确度。实际还受噪声、基准、非线性、输入驱动和时序影响。
- 为统一教学，若n位均匀量化器的全跨度为Vspan且有2^n个等宽区间，取`q=Vspan/2^n`；最近舍入时理想误差不超过q/2。码到端点的映射可能用不同约定，需查看实际设备定义。

## 自编算例：应变桥如何匹配ADC
沿用第3章教学应变：R=120Ω、ΔR=0.12Ω，桥压5V，只有R1增大。
1. 精确输出约−1.249375mV；小量近似−1.25mV。
2. 若放大100倍，输出约−0.12494V；检查放大器与ADC是否允许负输入和所需共模范围。
3. 12位、全跨度10V的教学量化器，q约2.4414mV，折回桥端约24.414μV/码。
4. 因而增益、噪声与量化必须整体预算；“12位”本身不能判定能否分辨目标应变。

以上接线与数值为自编，桥臂符号以本节定义为准，不是原书图5-4的原样复制。

## 反例与学习检查
- 相同方向变阻的两个桥臂放错位置，信号可能相消，而不是灵敏度翻倍。
- ADC先饱和再数字滤波，无法恢复被截掉的波形。
- 对ADC的位数和量化区间，混用符号位、满幅与全跨度定义，会产生约2倍错误。
- 能否解释为什么模拟抗混叠必须位于采样之前？能否用精确分压式验证桥路近似？

## 关联与核验边界
第2章用于合成动态响应；第3章决定激励与调理；第7章展开频混、泄漏与栅栏效应。本技能只视觉核验了关键桥路与采样页面，复杂交流桥图、滤波电路元件值与历史ADC参数必须回查。
