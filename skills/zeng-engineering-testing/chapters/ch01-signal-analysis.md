# 第1章：信号分析基础

**定位**：印刷p.6–43 / PDF第15–52页；重点1-2（p.9）、1-3（p.10）、1-4（p.15）、1-5（p.29）。

## 核心问题
先判断被测信号属于什么过程，再选择统计量、频谱或相关函数。不要把“计算出一条曲线”误当成“回答了工程问题”。信息是要提取的对象特征，电信号只是载体；只测与任务相关的成分。

## 决策框架
### 1. 分类后分析
1. 有可重复的确定性关系：区分周期、准周期与瞬态/非周期。周期信号用傅里叶级数和离散谱线；非周期信号用傅里叶变换和连续频谱。
2. 有明显随机性：先检查统计性质是否随时间变化，再区分平稳、非平稳及各态历经。
3. 只有在相应平稳性和各态历经假设合理时，才用一条足够长记录的时间平均代表总体统计特征。趋势、转速爬升、冲击开始与结束不能直接混在同一平稳模型里。
4. 在报告中写明分类依据、观察区间与舍弃的信息，而不是仅写“随机信号”。

### 2. 用问题选择特征
| 想知道什么 | 优先方法 | 仍需检查 |
|---|---|---|
| 是否有偏置 | 均值 | 零点、温漂、直流分量的物理意义 |
| 波动有多强 | 方差、标准差 | 是否已去均值 |
| 总体有效幅值 | 均方根 | 包含直流与否、单位 |
| 有哪些频率 | 幅值谱、自功率谱 | 观察时长、采样、归一化 |
| 噪声中是否有重复结构 | 自相关 | 周期假象与有限记录误差 |
| 两信号的延时与共同成分 | 互相关、互谱 | 延时符号约定、共同干扰 |
| 输入到输出如何改变 | 输入自谱与输入输出互谱 | 线性定常、激励能量、噪声位置 |

### 3. 时域与频域互相约束
时间伸缩、时移、频移和卷积是同一信号的不同表示。短时脉冲通常需要较宽频带；时移改变相位而不改变幅值谱；时域卷积对应频域乘积。使用这些性质先判断结果的方向，再计算详细积分。

## 必须区分的概念
- **均值、均方值、均方根**：量纲分别为原单位、原单位平方、原单位；均方值不是方差。
- **功率信号与能量信号**：持续存在的周期过程不直接套用有限能量脉冲的全部定义。
- **幅值谱与功率谱密度**：后者按单位频率计量，不能把一根谱线的高度直接作为信号幅值。
- **相关与因果**：互相关峰说明时间关系，不单独证明故障原因。
- **自谱与互谱**：自谱不保留相位；传递函数要用能保留输入输出相位关系的互谱。

## 可核验公式
印刷p.31 / PDF40，式(1-63)–(1-67)：

`均方值 = 方差 + 均值²`，`RMS = sqrt(均方值)`。

有限记录的离散实现为 `mean = Σx/N`、`mean_square = Σx²/N`、`variance = Σ(x-mean)²/N`。这里的方差用于描述该记录，不是带自由度修正的总体方差无偏估计。

印刷p.42 / PDF51，式(1-90)–(1-96)：`Y=HX`、`S_y=|H|²S_x`；按原书互谱约定，`H=S_xy/S_x`。不同软件可能交换互谱共轭方向，不能只凭相同下标照搬。

## 自编算例：总量与交流量
给定教学信号 `x(t)=2+3 sin(2π·50t)`，在包含整数周期且采样充分的记录内：
1. 均值为2；正弦项均值为0。
2. 方差为 `3²/2=4.5`。
3. 均方值为 `2²+4.5=8.5`，总RMS约2.9155。
4. 去均值后RMS为 `3/√2≈2.1213`。

如果需求是振动的交流强度，用2.9155代替2.1213会把偏置算进去。反过来，若要评价总电热效应，随意去掉直流也会错误。此例为自编，不是原书例题。

## 方法的失败模式
- 一条FFT图没有标明单位、单/双边谱或处理窗口，不能用于定量比较。
- 相关处理只能降低特定不相关噪声的影响；相关干扰不会自动消失。
- 提高显示插值密度不等于提高真正的频率分辨能力。
- 平均之前先看波形；少数饱和点可能制造大量伪频率成分。

## 学习检查
1. 为什么零均值时标准差等于RMS，而非零均值时一般不等？
2. 为什么两个自谱的比值不能提供完整相位？
3. 若设备转速在记录期间持续变化，为何不宜直接把整段作为平稳信号平均？
