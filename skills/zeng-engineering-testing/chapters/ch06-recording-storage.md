# 第6章：记录及存储仪器

**定位**：印刷p.177–194 / PDF第186–203页。磁带p.177；磁盘p.185；光盘p.190。

## 核心问题
记录系统保存的是之后还要正确解释的测量信息。容量不等于记录能力，写入成功不等于重放后幅值、频率、时序与单位仍然正确。

## 框架一：区分信息表示与介质
原书把磁带的直接记录、调频记录与数字记录分开讨论，并介绍磁盘的寻址/存取和光盘的记录、读出及类型。使用时分别回答：
1. 数据是模拟波形、调制后的波形，还是编码后的数字？
2. 通道需要保存直流、低频、宽带还是瞬态？
3. 记录和重放过程是否改变时间尺度、带宽或幅值？
4. 存取是顺序还是可随机寻址？需要连续采集还是离线分析？

磁带直接记录受感应读出机理及频带约束；调频记录以载波频率变化携带信息。不能因为都叫“磁带记录”，就认为能同样保存直流。原书中的磁带速度与磁道等规格只作为历史案例。

## 框架二：用六类性能评估记录链
| 维度 | 核对内容 | 错误信号 |
|---|---|---|
| 频带 | 记录/重放幅频与相频 | 波形变钝或峰值改变 |
| 噪声与失真 | 满量程、信噪比、非线性 | 弱信号淹没或削顶 |
| 时间基准 | 速度变化、抖动、同步 | 频率偏差或通道相位差 |
| 连续能力 | 总数据率、持续写入、缓冲 | 丢样、间断、积压 |
| 存取与容量 | 可用容量、检索方式 | 有容量但找不到记录 |
| 可解释性 | 通道、单位、量程、标定信息 | 有数字但不能复算物理量 |

最后两行中的数字数据管理要求属于本技能基于原书记录思想的工程化扩展，不是2002年教材提出的文件格式规范。

## 方法：从数据量反推记录方案
1. 用各通道采样率乘每样本实际存储字节数，再求和；别将ADC位数直接当文件字节数。
2. 将记录时长转为秒，算原始数据量，再加元数据和封装开销。
3. 明确峰值与持续吞吐的区别，并用实际写入验证。
4. 同步保存采样率、单位、比例系数、偏置、触发事件与时序异常。
5. 回读一段数据，与记录前的已知信号比较，确认解码、通道与幅值一致。

## 自编算例：为什么“硬盘很大”仍会丢数据
8通道，各20 ksample/s，每样本按4字节保存，持续30分钟。
- 数据率：`8×20000×4=640000 byte/s`。
- 原始数据量：`640000×1800=1152000000 byte`，即1.152 GB（十进制），约1.073 GiB（二进制）。
- 本计算不含文件头、索引、日志、冗余与余量。存储介质即使容量足够，写入延迟、缓冲不足或采集处理阻塞仍可能丢样。

该算例为原创教学场景，非原书器件性能比较。

## 反例
- 将磁带抖动引起的时间误差当作被测对象频率调制。
- 混淆B与bit、GB与GiB，造成容量和速率预算错误。
- 保存图像截图而不保存原始数值，无法重复计算RMS或频谱。
- 删除量程和校准信息后，重放时把ADC码当伏特。
- 把“只读、一次写、多次擦写”的区别当作可靠性或寿命的唯一判断依据。

## 学习与使用边界
学习时重点掌握表示、记录、重放及性能约束之间的关系；磁带、软盘、光盘的原书接口、容量与价格结论是历史资料，不作当前选购建议。关联第5章数字化、第7章连续采集和第8章软件解耦。现代文件元数据模板见仓库templates目录。
