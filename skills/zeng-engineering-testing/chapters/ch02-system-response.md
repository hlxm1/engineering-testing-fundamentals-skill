# 第2章：测试装置的静、动态响应特性

**定位**：印刷p.44–58 / PDF第53–67页。静态p.44–46；传递函数p.46–51；频响p.52–54；不失真p.54–55；典型输入响应p.55–57。

## 核心问题
测量链不只是“把输入乘一个数”。静态标定解决幅值映射，动态特性决定时变输入的幅值与相位能否保真。传感器、调理器、记录装置都要计入。

## 框架一：静态标定拆开评定
1. 用若干已知输入覆盖实际工作范围；保留升程和降程数据。
2. 明确拟合直线方法，计算灵敏度，说明输入、输出单位。
3. 将相对拟合直线的最大偏差与全量程输出比较，评定非线性度。
4. 比较相同输入的升降程输出，评定回程误差；不要将其与重复性混为一谈。
5. 另列分辨力、死区、稳定性和测量范围。高灵敏度不保证小误差，也可能同时放大干扰。

印刷p.45 / PDF54的非线性度与回程误差都以全量程输出为分母。这里不是以当前读数为分母；若更换定义须明确。

## 框架二：从物理模型到完整测量链
- **线性定常系统**：先检查工作点、幅值和时间范围内能否近似满足线性与参数不变。频率保持性指正弦稳态响应，不是任意初始瞬态都只含该频率。
- **传递函数**：零初始条件下 `H(s)=Y(s)/X(s)`。
- **串联**：可忽略相互负载影响时，`H_total=H_1 H_2 ...`；静态灵敏度也相乘，单位逐段相消。
- **并联**：同一输入下相应支路输出相加时，传递函数相加。没有相同输入与可加输出不能机械套用。

## 框架三：一阶、二阶模型用于判定动态误差
### 一阶
设单位静态增益：`H(s)=1/(τs+1)`。

`|H(jω)|=1/sqrt(1+(ωτ)²)`，`φ=-atan(ωτ)`，`ω=2πf`。

当频率升高，幅值衰减和相位滞后同时增加。截止点的约0.707增益不等于“不失真”。允许相对幅值衰减为ε时，可由上式推导 `f_max ≤ sqrt((1-ε)^(-2)-1)/(2πτ)`；这是依据模型的推导式，不是原书经验常数。

### 二阶
归一化形式 `H(jω)=1/(1-r²+j·2ζr)`，其中 `r=ω/ω_n`。

`|H|=1/sqrt((1-r²)²+(2ζr)²)`。

用 `atan2(-2ζr,1-r²)` 取相位，避免原书反正切简写在跨象限时产生歧义。固有频率、阻尼比、静态增益分别控制不同因素，不能只追求高固有频率。

## 框架四：不失真是“形状不变”
印刷p.54–55 / PDF63–64：`y(t)=A_0 x(t-t_0)`，对应工作频带内幅频特性恒定、相频特性线性。固定延迟本身不使波形失真，但闭环和多通道同步可能仍不能接受它。

检查顺序：确定实际信号频带 → 合成完整链频响 → 分别验幅值误差、相位/延时 → 判断波形要求。单频测幅与宽带波形重建的验收条件不同。

## 自编算例：温度传感器为什么“数值准但跟不上”
设时间常数τ=0.1 s、静态增益1。
- 测1 Hz正弦：`ωτ=0.6283`，增益约0.8467，相位约−32.14°；约15.3%的幅值损失，不能以静态校准合格作通过依据。
- 允许幅值损失5%：推得频率上限约0.523 Hz；但仍要单独判断相位允许值。
- 单位阶跃归一化响应 `1-exp(-t/τ)`；t=τ约63.2%，t=4τ约98.2%，t=5τ约99.3%。

数字为教学设定；代码见仓库examples，不代表某个实际传感器。

## 易错点与取舍
- 不把f（Hz）直接代入要求ω（rad/s）的式子。
- 带宽大、刚度高、灵敏度高往往不是同向优化；按允许误差选，不按参数排名选。
- 软件逆滤波会放大噪声，无法恢复已饱和、已混叠或被物理带宽完全抹去的信息。
- 通过标定识别一阶模型后，仍检查残差和高频响应，不能先假定所有传感器都是一阶。

## 学习检查与关联
给定完整信号链，应能同时写出总静态灵敏度及总动态模型，并用单位验证。与第1章频谱、第3章传感器和第5章滤波联合使用。公式视觉核验记录见references/formula-audit.md。
