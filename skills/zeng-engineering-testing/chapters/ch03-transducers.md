# 第3章：工程中常用传感器的转换原理及应用

**定位**：印刷p.59–121 / PDF第68–130页。目录与实际一致。传感器概述p.59；分类与选用p.60–65；电阻p.65；电容p.71；电感p.77；磁电p.81；压电p.84；磁敏p.89；热敏p.91；气敏p.96；超声p.99；光电p.103；光纤p.108；CCD p.110；生物p.113。

## 核心问题
把“被测量→敏感效应→电输出→调理要求”连起来选型。名称相近的电感、磁电、磁敏不是同一转换原理；输出是电阻、电容、电感变化时，还需要供能与转换电路。

## 选型流程
1. 明确被测量、静/动态、量程、频带、预期最小变化及允许误差。
2. 约束接触与否、温度、湿度、腐蚀、导电性、磁性、空间、安装刚度、可达性。
3. 列出至少两种可能的物理转换原理，比较对被测对象的扰动与交叉敏感。
4. 确认输出形式、激励电源、输入阻抗、电缆长度和后级调理匹配。
5. 做全链标定与动态检验，不以单只传感器参数替代系统指标。

## 原理—决策矩阵（原创整理）
| 类型 | 转换机制 | 适合的判断方向 | 首先排查 |
|---|---|---|---|
| 电位计 | 触点位置改变电阻分压 | 接触式位移、结构简单 | 磨损、接触噪声、负载效应 |
| 金属电阻应变 | 变形改变几何及电阻率 | 应变与弹性体间接测力 | 温度、粘贴、方向、弹性范围 |
| 电容 | 极距、面积、介电常数变化 | 小位移、厚度、液位等 | 寄生电容、屏蔽、非线性 |
| 自感/互感 | 磁路或耦合变化 | 位移、差动变压器 | 激励、解调、磁滞、零点 |
| 涡流 | 导电体中的涡流反作用 | 导电目标非接触测位移 | 材料、表面、温度、标定靶 |
| 磁电 | 相对运动改变磁通 | 动态速度、转速 | 低速输出、负载、磁场 |
| 压电 | 受力产生电荷 | 动态力、振动、冲击 | 泄漏、低频下限、电荷放大 |
| 霍尔/磁敏 | 磁场改变电特性 | 磁场、位置、电流间接测量 | 方向、温漂、励磁、杂散场 |
| 热电偶/热电阻 | 热电势/温度改变电阻 | 温度及其他热效应量 | 参考端、引线、自热、热惯性 |
| 气敏 | 吸附/反应改变电特性 | 指定气体检测 | 选择性、湿度、老化、交叉气体 |
| 超声 | 传播、反射、衰减 | 测厚、距离、探伤 | 声速、耦合、路径、盲区 |
| 光电/光纤 | 光通量或传播参数变化 | 非接触检测、强电磁环境 | 污染、光路、光源漂移 |
| CCD | 光生电荷积分及转移 | 成像、尺寸和位置 | 光学倍率、照明、像素标定 |
| 生物 | 识别元件与换能器耦合 | 特定生化量 | 活性、寿命、污染、校准 |

该表是由书中各节压缩成的选型辅助表，不复制原书表格，也不提供现行采购规格。

## 差动结构的判断
差动电容、电感及桥路常用于提高局部灵敏度、改善线性并抑制共同影响，但这些好处以两支路的对称性与匹配为前提。需要逐项检查：信号引起的变化是否反向？温度等干扰是否同向？后级是否真在作差？若没有这些条件，“差动”不自动等于“温度补偿”。

## 关键概念
- **能量转换型与能量控制型**：区分由被测对象直接提供输出能量与用外部能量受被测量调制的情况。
- **交叉灵敏度**：输出也响应非目标输入，必须通过结构、补偿或多参数模型区分。
- **应变片灵敏系数**：`ΔR/R=Kε`，小应变与适用温度下使用；K取对应器件校准值。
- **压电低频限制**：真实绝缘及后级存在泄漏；不可把“电荷与力相关”推成“无限长静态力都可可靠测量”。
- **被测对象加载**：传感器的质量、刚度、热容量和接触压力可能改变目标。

## 自编算例：应变到采集卡
给定R=120 Ω、K=2.0、应变500 με，则ε=500×10⁻⁶，ΔR=0.12 Ω。步骤：
1. 将微应变转换为无量纲，先算`ΔR/R=0.001`。
2. 用桥路把微小电阻变化转换成电压；桥臂位置与接线决定符号及是否可抵消温度。
3. 调整增益到ADC量程内，同时保留过载余量。
4. 用已知加载校验力—应变关系和全链灵敏度。只知道应变片K，不能直接得到力；还缺弹性体结构模型或标定。

本例为自编；不复用原书练习的给定数值。

## 反例
- 低速转动目标直接选只靠感应速度生电的方案，却未验证最低转速输出。
- 为导电金属标定的涡流探头直接用于另一种合金，仍沿用原灵敏度。
- 为获得更高信号反复增加桥压，忽视自热和零点漂移。
- 把生物、气敏的选择性当成绝对专一性，把概念介绍当作安全或医疗认证。
