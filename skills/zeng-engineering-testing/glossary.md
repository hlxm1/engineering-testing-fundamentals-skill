# 双语术语表

按英文名排序，括号为对应章；小节页码见references/source-index.json。

- **ADC / 模数转换** — 采样、量化、编码（5）。
- **Aliasing / 混叠** — 采样后频率不能唯一区分（7）。
- **AM / 调幅** — 被测量改变载波幅值（5）。
- **Autocorrelation / 自相关** — 同一信号与其延时的相关（1）。
- **Bridge / 电桥** — 以桥臂阻抗关系转换参量变化（5）。
- **Capacitive sensor / 电容传感器** — 极距、面积或介质变化换能（3）。
- **CCD / 电荷耦合器件** — 光生电荷存储与转移（3）。
- **Cross-correlation / 互相关** — 两信号相关性随延时的变化（1）。
- **Cross-sensitivity / 交叉灵敏度** — 对非目标量也有响应（3、4）。
- **Cross-spectrum / 互谱** — 互相关的频域表示（1）。
- **DFT / 离散傅里叶变换** — 有限序列到离散频点的映射（7）。
- **Differential sensing / 差动** — 组合反向变化以提取信号（3、5）。
- **Eddy current / 涡流** — 导电目标中感应电流的效应（3、9）。
- **Ergodicity / 各态历经性** — 特定条件下时间统计代表总体统计（1）。
- **FFT / 快速傅里叶变换** — DFT的高效算法（7）。
- **Frequency response / 频响** — 线性定常系统正弦稳态复数比（2）。
- **Fuzzy sensor / 模糊传感器** — 数值到语言概念的映射（4）。
- **Hall effect / 霍尔效应** — 磁场中载流材料的横向电势（3）。
- **Hysteresis / 迟滞** — 同输入升降程输出不同（2）。
- **Impedance / 机械阻抗** — 力/速度；倒数为导纳（9）。
- **Leakage / 泄漏** — 截断使谱成分向周围扩散（7）。
- **Membership / 隶属度** — 对模糊概念的符合程度，非概率（4）。
- **Nonlinearity / 非线性度** — 相对参考线的归一化最大偏差（2）。
- **PSD / 功率谱密度** — 均方贡献在单位频率的分布（1）。
- **Piezoelectric / 压电** — 力与电荷的耦合效应（3）。
- **Quantization / 量化** — 幅值映射到有限级（5）。
- **RMS / 均方根** — 平方平均后开方（1）。
- **Sensitivity / 灵敏度** — 输出变化/输入变化（2）。
- **SPL / 声压级** — 声压比的20倍常用对数（9）。
- **Stationarity / 平稳性** — 相应统计性质不随绝对时间变（1）。
- **Strain gauge / 应变片** — 应变到电阻变化（3）。
- **Thermocouple / 热电偶** — 热电势测温，需参考端条件（3、9）。
- **Time constant / 时间常数** — 一阶响应快慢参数（2）。
- **Transfer function / 传递函数** — 零初始条件下Y(s)/X(s)（2）。
- **Virtual instrument / 虚拟仪器** — 软件组织硬件、分析与界面（8）。
